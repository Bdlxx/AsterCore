# 栖星 AsterCore

> QQ 机器人多后端框架 · Windows 桌面版（规划中）

栖星（AsterCore）是一个面向普通用户的 QQ 机器人框架：双击即用、多账号、多后端（NapCat / 内置协议可选）、插件化（.py/.pyd/.dll）、带 Web 管理面板与自动更新。

- **品牌名**：中文「栖星」 · 英文 AsterCore（Aster=紫菀/小行星，Core=内核；与 bot 家族「依星/羽笙/星汐」星月意象一致）
- **主程序**：`AsterCore.exe`
- **完整计划书**：[docs/Windows版开发计划书.md](docs/Windows版开发计划书.md)（v0.5）
