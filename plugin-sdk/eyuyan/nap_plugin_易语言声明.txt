' NapApi 结构体（主程序注入）在 x64 下的偏移 —— 直接调用时按这个取指针：
'   偏移  0 : abi_version (int, 4 字节；后面 4 字节为对齐填充)
'   偏移  8 : action  函数指针  int action(char* action_json, char** out_json, int* out_len)
'   偏移 16 : log     函数指针  void log(int level, char* msg)      level: 0调试 1信息 2警告 3错误
'   偏移 24 : alloc   函数指针  void* alloc(unsigned long long size)
'   偏移 32 : free    函数指针  void free(void* p)
'   结构体大小 40 字节
' ─────────────────────────────────────────────────────────────
' 用 C 桥时（推荐）不需要关心偏移，直接声明这几个 DLL 命令即可：
'   .DLL命令 nap_bridge_init, 整数型, "nap_bridge.dll", "nap_bridge_init", , 公开
'       .参数 api, 整数型
'       .参数 abi_version, 整数型
'   .DLL命令 nap_bridge_log, , "nap_bridge.dll", "nap_bridge_log", , 公开
'       .参数 level, 整数型
'       .参数 msg, 文本型          ' 桥内部转 UTF-8
'   .DLL命令 nap_bridge_action, 整数型, "nap_bridge.dll", "nap_bridge_action", , 公开
'       .参数 action_json, 文本型
