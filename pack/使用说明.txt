栖星 AsterCore v0.6.29 · Windows 使用说明
==========================================

一、这是什么
------------
一个 QQ 机器人框架：多账号、可换后端、插件式、自带网页面板。
面板地址默认 http://127.0.0.1:8080 （启动后会自动打开浏览器）。

解压后约 200 MB（本次起**自带视频解析的依赖与 ffmpeg**，所以比上一版大很多）。


二、怎么运行
------------
1. 把整个文件夹解压到任意位置（注意：astercore.exe 和 _internal 文件夹必须在一起）
2. 双击 astercore.exe
3. **不会弹黑色控制台窗口**（v0.4.1 起是窗口模式）。日志看两处：exe 旁边的
   console.log、以及面板里的「运行日志」
4. 首次运行请去面板的「连接引导」页（http://127.0.0.1:8080/guide）选运行方式 ——
   选「内置协议直登」会要求勾「我已知晓风险」（实验特性，建议小号）
5. 会自动打开内嵌窗口；点窗口的 X = 隐藏到托盘（退出请用托盘菜单）
6. 首次运行会先进「首次设置」页：三选一（NapCat 推荐 / 内部协议有风险 / 稍后选择），
   左下角有「设置」（安全设置：无鉴权或密码鉴权；页面模式与端口：窗口模式/端口模式，默认 34567）

目录说明（首次运行自动生成，都在 exe 旁边）：
  data\       账号数据、插件配置、运行状态
  accounts\   账号连接配置
  plugins\    插件目录 —— 把 .py/.pyd/.dll 放这里就会被加载（已预置 2 个示例插件）
  console.log 启动/运行日志（窗口模式没有控制台，日志落在这里）
  runtime.log 运行日志
（转码器 ffmpeg 也随包放在 _internal\tools\ffmpeg\bin\ 里，程序会自己找到，你不用管）

首次运行被 SmartScreen / 杀软拦下怎么办
---------------------------------------
本程序**没有代码签名证书**，Windows 对"从网上下载的未签名 exe"会弹
「Windows 已保护你的电脑 / Microsoft Defender SmartScreen 阻止了无法识别的应用启动」。
按下面任一方式处理（②最省事）：
  ① 解压前：右键下载的 zip → 属性 → 勾「解除锁定(Unblock)」→ 确定，再解压
     （对 zip 做一次，解出来的所有文件都干净）
  ② 已经解压了：右键 astercore.exe → 属性 → 勾「解除锁定」→ 确定
  ③ 已经在弹窗里：点「更多信息」→「仍要运行」；杀软误报就把它加进信任/排除项
为什么会被拦：PyInstaller 打包 + 未签名 + 新文件信誉低。**彻底消除需要买代码签名证书**，
当前只能靠上面的"解除锁定"。


三、让机器人上线（需要 NapCat）
--------------------------------
AsterCore 负责"跑插件"，NapCat 负责"连 QQ"。两者配合：

1. 安装 NapCat（Windows 版），登录你的 QQ 小号
2. 在 NapCat 里打开 WebSocket 服务器，端口用 3001
   （NapCat 配置 → 网络配置 → 添加 WebSocket 服务端，端口 3001）
3. 打开 AsterCore 面板 → 账号 → 「+ 新建账号」：
     账号ID   : 你的 QQ 号，例如 123456789
     显示名   : 随便写，例如 我的机器人
     WS 地址  : ws://127.0.0.1:3001
     HTTP     : http://127.0.0.1:3000
     token    : 若 NapCat 设了 access_token 就填，否则留空
4. 保存后点该账号的「启动」，状态变成"运行中"即连接成功
5. 用另一个 QQ 给机器人发"你好" —— 示例插件会回复"你好呀～"

更快的办法（推荐）：启动后打开 http://127.0.0.1:8080/guide —— **连接引导页**把
「装组件 → 写配置（自动端口/token）→ 启动扫码 → 测连接」一次走完；
首启时如果组件还没装，程序会直接把你带到这一页。

引导页还能**一键建账号**（第⑥步）：填 QQ 号 → 选连接方式 → 「一键建好并启动」——
组件配置（端口/token）会自动对齐到该账号。已有账号的「连接方式」也能在那里逐个改
（OneBot/NapCat、内置协议直登、演示模式可**按账号**混用；改完若账号在运行会自动重启）。


四、插件怎么用
--------------
· plugins\ 目录下已预置两个示例（demo_hello.py 打招呼 / demo_counter.py 计数器）
· 自己写插件：复制示例改一改即可，改完在面板点该插件的「重载」
· 面板里可以对每个账号单独启用/停用插件、编辑插件配置（保存即热更）
· 插件开发文档见仓库 README 与 plugin-sdk\ 目录


五、视频解析（本次新增：依赖与 ffmpeg 已随包）
--------------------------------------------
把视频解析插件（video_parser.py + video_parser_core\ + parser_bridge.py）整个放进
plugins\ 即可，**不需要再装任何东西** —— Python 依赖（36 个包）与 ffmpeg.exe
都在包里了。

· 支持的平台：B站 / 抖音 / 微博 / 小红书 / 快手 / YouTube / TikTok / Twitter /
  知乎 / 西瓜视频 / 皮皮虾 / acfun / ncm / iwara / instagram / pixiv 等
· 群里发链接就会被解析（受"分群开关"控制，默认关，需在面板里按群打开）
· B站登录（扫码拿高画质）/ 抖音等平台的 Cookie：在插件配置里按提示填，
  Cookie 会自动存到 data\ 下并自动续期
· 首次启动时留意日志里这一行：
    [解析器] 已启用平台: acfun、bilibili、…
  它列出**真的能用的平台**；若某个平台依赖坏了，会在下一行明确写出是哪个平台
  （不再像以前那样整包失效、毫无提示）


六、常见问题
------------
Q: 控制台一直显示重连 / 面板显示"未连接"
A: NapCat 没启动，或端口不对。确认 NapCat 里 WebSocket 服务端已开且端口是 3001。

Q: 发链接"没反应"
A: 依次看三处：① 日志里有没有 `[解析器] 已启用平台:` 这一行；
   ② 该群的分群开关是否打开（面板 → 群组）；③ 该平台是否需要 Cookie/登录。

Q: 提示 ffmpeg 找不到
A: 随包就带着（_internal\tools\ffmpeg\bin\ffmpeg.exe）。若被杀软/清理工具删了，任选一种补回：
   把 ffmpeg.exe 放到 <解压目录>\tools\ffmpeg\bin\（程序也认这个位置）、加进系统 PATH、
   或设环境变量 FFMPEG_PATH 指向它。

Q: 浏览器打开是旧界面
A: 按 Ctrl+F5 强制刷新（浏览器缓存）。

Q: 杀毒软件报警
A: PyInstaller 打包的 exe 常被误报，添加信任即可。

Q: 提示端口被占用
A: 程序会自动改用下一个端口，注意看控制台里实际打印的面板地址。

Q: 想把数据挪到别处
A: 设置环境变量 ASTERCORE_HOME=目标目录，或启动时加 --data-dir/--accounts-dir。


七、数据与安全
--------------
· 所有数据都在本机，不上传任何服务器
· 账号 token 保存在 accounts\<QQ>\backend.json，别外传
· 建议用小号测试；面板默认仅监听 127.0.0.1，可在面板「安全设置」里加密码或 Token
