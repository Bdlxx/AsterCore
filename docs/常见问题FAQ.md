# 栖星 AsterCore · 常见问题（FAQ）

> 面向使用者。所有路径以「解压后双击 `astercore.exe`」的用法为准。

---

## 一、第一次运行

### 1. 双击没反应 / 弹「Microsoft Defender SmartScreen 阻止了无法识别的应用启动」

这是 Windows 对**未签名**程序的常规拦截，不是病毒告警。三种解法，从推荐到将就：

| 做法 | 步骤 |
|---|---|
| **解压前先解除锁定**（最干净） | 右键下载到的 **zip** → 属性 → 勾选「解除锁定(Unblock)」→ 确定 → 再解压 |
| 对已解压的 exe 解除锁定 | 右键 `astercore.exe` → 属性 → 勾「解除锁定」→ 确定 |
| 直接放行这一次 | 弹窗里点「更多信息」→「仍要运行」 |

> 想**彻底**没有这个弹窗，只能买代码签名证书给 exe 签名，当前版本做不到，所以文档里统一按上面处理。

### 2. 启动后没有窗口，但托盘有图标？

正常行为：点窗口右上角 **X** = **隐藏到托盘**（不是退出）。左键单击托盘图标可以**显示/隐藏**面板，
右键托盘图标有菜单：显示面板 ｜ 昵称 ｜ 状态 ｜ 启动/停止机器人 ｜ 重启机器人 ｜ 退出软件。

**真正退出**请用托盘菜单里的「退出软件」。

### 3. 日志在哪里？

`<程序目录>\console.log`（双击启动时控制台被隐藏，日志写在这里）。
面板里的「运行日志」页看的是**机器人**的日志，两个不是一回事。

## 二、连接引导（建第一个账号）

面板 → 管理 → **连接引导**（或账号页顶部入口）：

| 步骤 | 说明 |
|---|---|
| ① 下载并安装组件 | **NapCat**（推荐路线）：后台跑官方 QQ 客户端 + NapCat 中间层，走官方登录通道，风控最低。需要能访问 GitHub |
| ② 写配置 | 自动生成端口与令牌，并把 `ws 地址 + 令牌` 显示出来（要和账号里写的一致，否则连上也发不出动作） |
| ③ 启动并取二维码 | 启动组件、显示二维码，用手机 QQ 扫码登录 |
| 一键建好并启动 | 填 QQ 号 → 直接**建好账号并启动**（推荐，省去手抄 ws/令牌） |

**内置协议（Lagrange）不用下载**：它**随软件自带**（面板 → 设置 → 运行方式 → 内部协议）。
纯协议直登、免装客户端，但属**非官方协议**，有限制登录/封号风险，**建议只用小号**。

### 4. 组件下载失败 / 卡住

- 先看「看日志」按钮里的输出，确认是网络问题还是磁盘问题
- 需要能访问 `github.com`；公司网络/代理环境下可能被拦
- 下载大文件（NapCat 约 118 MB）失败可以直接重试；已下载成功的部分会重新开始
- 实在下不动：手动下载官方包，解压到 `<程序目录>\components\napcat\`（里面有 `NapCatWinBootMain.exe` 之类即可）

## 三、账号与运行

### 5. 点「启动机器人」一直停在"启动中…"或报错

- 「启动中/停止中」期间按钮是禁用的，等它结束
- 失败会进入**错误**态并写日志；错误态下按钮文案回到「启动机器人」，再点一次会重试
- 常见原因：组件没装（先走引导第①步）、ws 地址/令牌与组件配置不一致（用「一键建好并启动」可避免）、端口被占用

### 6. 账号建好了但收不到消息

依次确认：① 组件在跑 ② 账号状态是「运行中」③ ws 地址与令牌和组件配置**完全一致**
④ 插件是否启用（面板 → 插件配置）。机器人状态（已停止/运行中）指的是**本程序内部核心**，
与 NapCat 是否在线是两回事。

### 7. 多个账号能同时用不同的连接方式吗？

能。**每个账号独立**选择连接方式（NapCat 外部 / 内置协议 / 演示模式），可以在账号列表里逐个切换；
切换时如果账号正在运行会自动重启，并自动把组件配置对齐到该账号。

## 四、设置

### 8. 面板和托盘里的状态不一样？

不会。两者读的是**同一份状态**（托盘菜单与主界面按钮同源），所以文案与禁用态永远一致。
如果发现不一致，请截图反馈（这是 bug）。

### 9. 页面模式：窗口模式 与 端口模式

- **窗口模式**（默认）：内嵌窗口，不需要任何端口
- **端口模式**：在本机开一个 Web 端口，可用浏览器访问（适合手机/别的电脑来看面板）
  端口默认 **34567**，改完**重启程序**生效

### 10. 无鉴权 / 密码鉴权

本机自用可以「无鉴权」；只要**对外监听**就必须设密码（启动前会拦，避免裸奔）。
密码只保存**哈希**，不存明文。忘记密码：删掉 `<程序目录>\data\auth.json` 后重启（回到无鉴权）。

## 五、更新

### 11. 怎么更新到新版本？

面板 → 设置 → **关于与更新** → 检查更新 → 下载并校验 → **重启以应用更新**。
流程：检查 → 下载 → **sha256 校验** → 解压暂存 → 退出程序 → 替换目录 → 自动重新打开。

- 若 Release 没有附校验文件，界面会显示"未校验"（**不会假装校验过**）
- **新版起不来会自动回滚**到旧版本（两阶段：新版启动成功才写"确认"标记）
- 想手动更新：直接下载新 zip，解压覆盖 `<程序目录>`，账号与数据都在 `accounts\` / `data\`，不会被覆盖

## 六、其它

### 12. 数据在哪？换电脑怎么搬？

```
<程序目录>\
  accounts\<QQ>\backend.json    ← 每个账号的连接方式与地址
  data\                         ← 运行配置（runtime.json / auth.json 等）
  plugins\                      ← 插件（.py / .pyd / .dll）
  components\                   ← 引导下载的组件（NapCat 等）
```
**只需搬 `accounts\` + `data\` + `plugins\`**（`_internal\`、`components\` 是程序本体与组件，重装/重新引导即可）。

### 13. 插件放哪、怎么写？

放 `plugins\`（`.py`），或发布构建的 `.pyd`（防改）。示例见程序目录 `plugin_templates\`，
接口草案见 `docs\ABI草案.md`。

### 14. 卸载

删掉整个程序目录即可；注册表只写版本信息，无残留服务。（**不会**在你的 QQ 上做任何注销操作。）
