## 〇、一句话说清本轮改了什么

**旧架构**：`ShellApp` 把 `http://127.0.0.1:8080` 套进一个 pywebview 窗口 —— 桌面版
**被迫占端口**，还必须处理浏览器那套登录态。手册 §1.2/§1.5 要的"进程内 RPC"根本不存在。

**新架构**：

```
桌面窗口(file:// 本地面板文件)
   └─ window.pywebview.api.rpc(method, params)      ← js_api，进程内
        └─ RpcHub.dispatch                          ← 单一 dispatch（手册 §1.4）
             ├─ 语义方法：web.test_port / app.quit / window.hide / app.info
             └─ "/api/..." → Flask test_client（进程内）→ 同一条路由代码
   ── 浏览器模式仍然可用：HTTP /api/*（Web 服务默认关闭，要用才开）──
```

关键取舍：**不重写 585 行的面板路由**，而是让进程内调用也走同一条路由
（`test_client`，不经过 socket）。于是手册 §1.4 的验收"两条通道返回一致"是**结构上成立**的，
以后加功能也只写一个 Flask 路由、两条路自动都能用。

## 一、架构层

| 手册项 | 现状（动手前） | 本次 | 验收 |
|---|---|---|---|
| §1.1 宿主形态 pywebview | ✅ 已有 `shell.py`：`create_window` + 尺寸 + `min_size`。**但没挂 `js_api`**，窗口加载的是 HTTP URL | 保留尺寸/`min_size`，新增 `confirm_close=False`、`js_api`、本地文件加载 | `tests/test_desktop.py::test_desktop_mode_js_api_no_listener` 断言 `js_api` 非空 且 url 以 `file:` 开头 |
| §1.2 js_api 进程内 RPC | ⬜ 不存在 | 新增 `rpc.py`：`RpcHub` + `JsApi.rpc`（只暴露一个公开方法） | `test_js_api_exposes_only_rpc`：公开可调用成员**只有** `rpc`（手册 §1.1 的坑：`_` 开头不暴露） |
| §1.3 可选 Flask + **waitress** | ⚠️ 用 Flask 内置服务器（`app.run(threaded=True)`） | 优先 waitress（`threads=32`），没装则**明确告警**后回退内置服务器；waitress 进 `[web]/[desktop]` extra + spec | 本机未装 waitress → 日志出现告警 + 回退（这本身也是被验证的路径）；装了就 32 线程 |
| §1.4 RPC 中枢单一 dispatch | ⬜ 无（HTTP 与前端直接耦合） | `RpcHub.dispatch`：语义方法 + HTTP 路径转发；**永不抛异常** | `test_inline_call_matches_http`（两通道 data 完全相同）、`test_handler_exception_is_converted`、`test_unknown_method_returns_error_not_raise` |
| §1.5 前端 transport 自动选择 | ⬜ 前端只有 `fetch('/api/...')` | 前端新增 `Transport`：`file:` 协议或 `pywebviewready` → js_api，否则 HTTP；并装 **fetch 垫片**把同源请求转成 js_api | 浏览器级 `tools/verify_desktop_transport.py`：A 浏览器模式 / B 桌面模式 / C **延迟注入**（`pywebviewready` 路径）全部通过 |

> **为什么用 fetch 垫片而不是改写 5 处调用点**：既有 5 处 `fetch` 里 4 处是直接 `fetch(...)`
> 而不是走统一的 `j()`。垫片让**将来新增的前端代码也自动走对通道**，不用靠人记得。

## 十一、如何自己复现全部验证

```bash
cd /root/astercore
python3 -m unittest discover -s tests                 # 144 项（新增 24 项：RPC/桌面壳/单实例/Web 规则）
python3 tools/verify_desktop_transport.py             # 浏览器级 12 项（两种通道 + 延迟注入 + 日志 DOM 上限）
python3 -m PyInstaller pack/astercore.spec --noconfirm --clean   # 打包
python3 tools/e2e_frozen.py --browser                 # 打包产物端到端
python3 -m astercore --web --port 9000 --no-browser   # 手动起 Web 服务看看
```
